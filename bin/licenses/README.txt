Third-party command-line tools bundled with FLAC Cleaner (unmodified):

  flac.exe, metaflac.exe 1.5.0  - Xiph.Org FLAC tools, https://xiph.org/flac/
                                  The flac/metaflac programs are GPL-2.0 (flac-tools-COPYING.GPL.txt);
                                  libFLAC (FLAC.dll) is BSD-3-Clause (FLAC-COPYING.Xiph.txt).
                                  Source: https://github.com/xiph/flac (tag 1.5.0)
  ogg.dll 1.3.5                 - Xiph.Org libogg, BSD-3-Clause (ogg-COPYING.txt)
  vcruntime140.dll              - Microsoft Visual C++ runtime (redistributable)

Binaries taken from the conda-forge win-64 packages libflac 1.5.0 and libogg 1.3.5.
FLAC Cleaner runs these tools as separate programs.
